# 🛠️ Hikers CV352-C42 Smart TV Unbrick Kit (HiSilicon / Titan OS)

* `TitanLauncher.apk`: Lanzador de sistema original de Titan OS.
* `boot.img`: Partición del kernel de arranque (40 MB).
* `recovery.img`: Partición del sistema de recuperación (40 MB).
